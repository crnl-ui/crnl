Stat Table

The stat table — every cell and row state, with a pinned leading column that scrolls.

A standings or stat table: one wide identifying column, then as many narrow numeric ones as the data has. The numbers cannot all fit on a phone, so they scroll horizontally while the entity stays pinned — a number you can read but cannot attribute is useless. Narrow the window and scroll the table sideways.

Like .tag, this component sets structure and colour only — you add the type class: labelBold10 on head cells, labelRegular20 on attribute cells, labelBold20 when sorted, title50 on the title band.

Tuning

--stat-table-entity-width

The leading column is 224px by default; set the custom property on the table to retune it. Attribute cells are a fixed 48px, and a table of long strings needs table-layout: fixed and a definite width or the value spills into the next column. Vertical scroll is the page's job — the component leaves overflow-y visible.
