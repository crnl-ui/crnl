Rows, Tags & Controls

Every slot, gap, state and subcomponent of the list row — plus the selector, the event row, tags and chips.

One structure: .list-row > optional .leading + .list-row-content + optional .trailing. All three slots are optional. Inside a row the text pair is .list-row-text-pair, never .card-text-pair (RULES §4).

A .list-row carries no padding, no margin and no border — its container does. Two correct containers: a flex column with .list-gap / .list-gap-tight, or a wrapper that carries the padding and a hairline (called .row-wrap on this page, defined once in sheet.css).

Selector

.selector wraps a .list-row to make it selectable

The selector supplies the 16px radius and the padding; the surface class supplies every interactive state. surface-washNeutral when it sits inside a card, surface-card when it sits on the page background. .is-selected inverts and beats both surfaces; .is-disabled is 25% opacity and takes no scale.

Tags and chips

tag-chip-components.css

A tag is a static label badge. A chip is an interactive filter or toggle, and gets its states from a surface + scale pair — never a :hover rule. Both are 32px tall with a 4px radius; the label class is yours to add.
