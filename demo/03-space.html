Space & Layout

The spacing scale, containers, radius, borders, grids and icons — with every utility class the system ships.

An 8px scale. Use var(--spacing-N) in CSS or the matching utility class in HTML — never a raw px, em or rem (RULES §2). For layout, prefer the responsive semantic tokens: they already know about the three breakpoints, so you do not write a media query (RULES §9).

Icons

icons.css · Material Symbols Rounded

A standalone icon is <span class="icon icon-N">name</span>. Icons are filled by default; add .icon-outlined to opt one out. Never add material-symbols-rounded next to .icon — .icon already sets the family. Inside a button it is .btn-icon material-symbols-rounded instead (RULES §4).
