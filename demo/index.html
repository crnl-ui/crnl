The nine nevers

RULES §2 — the short version

A sticker sheet shows you what exists. These are the things that don't, no matter how natural they feel to write. Full text in RULES.md.

palette
Never hardcode a colourNo #hex, no rgb(), no rgba(). A literal as a var() fallback is fine.
format_size
Never set font-size, font-weight or line-heightUse a text class. Stepping down on mobile is a -r pair, not a media query.
straighten
Never hardcode spacingNo raw px, em or rem. A spacing token or a utility class.
touch_app
Never write :hover or :activeA .surface-* and a .scale-* on the same element are the mechanism.
layers
Never sit a solid surface on another solid surfaceBase → surface → sheet is a ladder you climb once. On a card, use a wash.
crop_free
Never put a border on a card--bg-surface against --bg-base is the edge.
smart_button
Never use a bare button, select or inputDemos and utility controls are not exempt. Every button carries a DS class.
contrast
Never use --brand-interactive or --brand-inverted in a componentThey are mode-stable, so one mode renders dark on dark. Use --color-interactive / --color-inverted.
database
Never hardcode names, dates, prices or fixturesIt comes from the project’s own content layer — on these sheets, the synthetic one in demo-content.js.

Keeping it honest

check-coverage.mjs

A sticker sheet is only worth something if it is complete, and it stops being complete the moment somebody adds a class. So completeness is checked, not claimed:

npm run check:demo

It reads docs/css-api.json — the generated index of what the CSS actually ships — and reports two kinds of drift. Missing: a class or token in the CSS that appears on no sheet, which means new system surface nobody has documented. Unknown: a class used on a sheet that is not in the CSS, which means either an invented class or scaffolding that needs declaring. It exits non-zero on either, so it can gate a build.

Two ways a class counts as covered: a live specimen, or its name printed in the page copy. Both are legitimate — a listing is how 300-odd spacing utilities get shown without 300 identical boxes.
