Buttons

Every button type at every size, in every state — plus circle buttons and the one vendor control.

Compose .btn + type + size. Sizes are .btn-700 (56px), .btn-300 (40px) and .btn-100 (32px). Disabled is the disabled attribute, never a class. Every row below shows all three sizes, then the disabled state.

.btn and .btn-circle already carry their interaction tier internally — never add a .scale-* to one, and never write :hover or :active (RULES §2).

Vendor chrome

system-ui.css

The one exemption from the token and type rules: controls specified by Apple or Google that a prototype reproduces rather than designs. Vendor colours as literals, vendor type, no response to theme or mode — theming an Apple button to the theme's brand would make it wrong. The exemption lives in that file and is never claimed inside a template (RULES §7).
