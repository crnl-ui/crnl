Layout architecture

a three-layer absolute stack

Content scrolls behind translucent chrome, so the two chrome layers sit above the scrollport and the scrollport fills the frame. .ios-scroll-inner's margin-top is measured at runtime, because the chrome gets taller when subtabs are present — a static copy bakes the measured value in instead (≈119px with the standard nav, more with subtabs).

Glass and buttons
.ios-glass .ios-nav-btn .ios-nav-btn-brand

.ios-glass is the frosted surface matching Figma's "Fake Glass" style — blur, a luminosity-blended tint, a hard-light overlay gradient, a 175° bevel ring through a mask, and a soft drop shadow. Semantic tokens throughout, so it holds across every theme and both modes. Apply it to any element and give that element its own radius.

Bottom tab bar
.ios-tab-bar .ios-tab-bar-inner .ios-tab .ios-tab-label .ios-tab-brand-icon

Five tabs on a glass pill over an --org-base gradient fade. Inactive is an outlined icon in --neutral-500; active is filled, in --ios-selected-tab, on a --ios-selected-tab-bg pill. The brand tab draws a themeable monochrome SVG through mask-image from --brand-tab-icon, so it inherits currentColor for both states.

Modal sheet
.ios-modal-backdrop .ios-modal-stack .ios-modal-sheet .ios-nav-modal .ios-nav-modal-row .ios-modal-content

Show and hide by toggling .is-open on the backdrop — that one class drives the backdrop fade, the sheet's slide and the stack indicator's delayed reveal. The hidden attribute works too but skips the animation, because display: none applies instantly.

Why hidden needs a rule at all. .ios-modal-backdrop sets display: flex, and an author declaration beats the browser's own [hidden] { display: none } on cascade origin — before specificity is even considered. Without the explicit .ios-modal-backdrop[hidden] guard, a modal marked hidden renders open, covering the screen. Every flex or grid overlay has the same trap. Building this sheet is how it was found: the guard, the backdrop's closed state and the sheet's slide are all in ios-nav-components.css now, where four native templates had been carrying byte-identical copies of them.
