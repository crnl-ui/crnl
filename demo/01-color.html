Color

Every colour token in the design system, resolved live for the theme and mode you have selected.

Every value below is read live out of getComputedStyle, so it is what the browser actually paints for the theme and mode selected in the switcher — not what the CSS source says. Switch theme or mode and the whole page re-resolves.

Never hardcode a colour — no #hex, rgb() or rgba() in a prototype (RULES §2). Reach for a semantic token first, a brand token second, an alpha scale last.
