Four families. Pick the family, then the step. Bold/Regular is weight, the number is size. Metrics next to each name are read live — switch theme and the display ramp changes with it, because a display font and its ramp travel together (RULES §6).

Never set font-size, font-weight or line-height (RULES §2). And write display text in title case — a caps face has it baked into the font, so a hardcoded "BUY" breaks every theme on a face that renders as drawn (RULES §5).

Responsive pairs

-r suffix

Stepping type down on mobile is a -r pair, not a media query. .title50-r is 20px/700 on desktop and 16px/600 below 500px. Narrow the window and the metrics below change. Adding a font-size override in a template is always wrong — add a pair to text-styles-system.css instead (RULES §5).

Transformthere are none, and that is deliberate

Never force letter case (RULES §2). Case belongs to the copy and to the theme's display font, which bakes it in — which is why every text class above sets text-transform: none. Four case utilities used to live here; they carried !important and overrode that for every theme at once, so an uppercase heading shouted in every theme whose face does not render caps. They were removed. Write the string the way it should read.
